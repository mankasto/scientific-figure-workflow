# Contributing

Contributions are welcome through issues and pull requests.

Keep stage interfaces stable. When changing a handoff file or QA rule:

1. update the relevant skill reference;
2. update the validator when the rule is machine-checkable;
3. include a small fixture or example job showing the change;
4. do not vendor third-party projects without checking license compatibility.

Report generated-image backends and licenses accurately. Do not include unpublished papers, private figures, API keys, or confidential datasets in issues or fixtures.
